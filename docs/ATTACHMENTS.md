# 附件支持

## 查看本机文件

将图片、PDF 或其他文件保存到当前项目，告诉 Claude 文件路径即可。图片和 PDF 可以传给远端 Claude；其他文件由 Claude 根据任务调用本机工具处理。

插件不会自动抽帧、转码或压缩文件。大小与格式说明见 [FAQ](FAQ.md#为什么拖入的附件不可用)。

## 拖入和粘贴图片

官方 CodexHost 自 0.17.0 起已包含附件传递修复（[PR #654](https://github.com/BytePioneer-AI/codex-host/pull/654)）。插件支持的 0.20.0 及以上版本直接支持拖入、粘贴图片和运行中追加图片，不需要额外安装修复包。

- VPS 端依赖为 CodexHost 0.22.0 及以上时，拖入或粘贴的图片会作为原生图片直接交给 Claude，不需要它再调用一次 Read。格式、大小或尺寸不符合官方要求的图片（例如运行中追加的超大图）仍保留缓存路径，由 Claude 按需读取。
- 只发图片、不写文字也可以识别。
- 图片和文档可以一起附加；只有 Desktop 附件清单中标记为图片的文件会作为图片传给 Claude。
- 正文里写的路径、代码示例和 Markdown 链接不会被当作附件。
- 单个图片或 PDF 超过 5 MiB 时，插件把路径和大小交给 Claude，由它决定怎么处理，不会自动压缩。
- 重复读取同一文件时，插件会重新检查授权和内容哈希，确认未变化后复用缓存，不重复传输。

## 从附件修复包迁移

0.13.x 及更早版本为 CodexHost 0.16.1 提供过独立的附件修复包。现在已停止维护：

- 安装官方最新版宿主即可，新安装会替换修补过的宿主文件，无需先恢复。
- 不要把旧修复包用在新版本宿主上，也不要用旧宿主备份覆盖新版宿主。
- 旧修复包的下载与恢复说明保留在对应版本的 [Release](https://github.com/vv-get-ti/claude-vps-bridge/releases) 中。

插件安装脚本不修改宿主文件。宿主与插件的版本对应关系见[维护说明](OPERATIONS.md#升级)。
