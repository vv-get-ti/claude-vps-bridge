# 可选工具与配置接口

接口的目的，是让工具配置与桥接核心分开维护。它不提供任意脚本自动加载、任意 MCP 自动放行或凭据导出能力。

## 当前已有的入口

- `installer/configure.py` / `installer/bridge_config.py`：非敏感连接与路径设置。
- `installer/prepare-mcp.py`：显式改变选中的工具配置，其他条目保持原样。
- `installer/prepare-local.py --with-playwright`：单独准备可选的本机浏览器依赖。
- `plugin/runtime/mcp-runtime.mjs`：本机 MCP 进程、会话绑定、目录与工具过滤。
- `remote/mcp-local.py`：原生 Claude stdio MCP 与现有双向 SSH 工具通道之间的转发。
- `remote/workspace-guard.py`：把远端工具调用交给本机权限检查。

目前正式支持的工具是 Tavily 和 Playwright。`prepare-mcp.py` 保留其他已有配置条目，不代表桥接权限层已经支持它们。

## 新增一个工具时

1. 写清执行位置：VPS 网络请求，还是 Windows 本机进程。
2. 写清配置：公开示例与非敏感参数可以进入仓库；密钥与私有头只能保存在使用者环境。
3. 在独立模块中实现工具定义和启动，不让基础连接依赖该工具的安装或登录。
4. 为工具调用增加对应权限映射，区分读取、写文件、执行程序与外部动作；不要用工具名正则把所有操作一律放行。
5. 定义进程关闭、超时、取消和断线后的行为。未知结果不能自动换编号重试。
6. 覆盖启用、禁用、未安装、缺少授权、查询失败、跨项目访问和用户取消。

新增接入应修改相关模块与契约测试，不应添加散落在连接、额度或项目映射代码中的特殊分支。等出现多个真实同类接入后，再提取必要的公共注册接口。

## 私有数据不需要公开读取接口

Claude 登录由官方 Claude Code 完成。桥接只调用已登录的远端运行时；不要增加“导出 token”“上传账号”或读取凭据正文的调试接口。

诊断应输出连接阶段、错误码、兼容版本和是否已配置等状态，默认隐藏账号标识、授权头、项目内容和原生对话。未经审查的真实运行日志不能作为测试 fixture 提交。
